# Mechatronics Quiz App

## Description
A Python-based multiple-choice quiz application designed to test basic knowledge of mechatronics, automation, sensors, and control systems.

## Features
- Multiple-choice questions
- Random question arrangement
- Different difficulty levels
- Automatic score calculation
- Bonus points for consecutive correct answers
- Percentage and performance grade
- Instant feedback on answers

## Requirements
- Python 3

## How to Run
1. Download the Python file.
2. Open the file in Python or Visual Studio Code.
3. Run the program.
4. Answer the questions by entering A, B, C, or D.
5. View your final score and performance.
